# A Custom From Scratch CLI Code Assistant

- Using Python 3.14 as the base, calling various LLMs through the [Open Router API](https://openrouter.ai/).
- We will be able to scan the current parent or child directories for all or designated files to supplement our LLM messages.
- I will be narrowing the LLM search and generation parameters to reduce wandering and hallucinations.
